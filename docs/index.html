One command surface

Built for useful, controlled work.

OM connects conversation to calendar, email, tasks, projects, meetings, documents, private knowledge, research, local models, and integrations. The user remains the authority for sensitive side effects.

01 / COMMAND

Chat with context

Search, attachments, voice, linked records, models, sources, retries, exports, and private session history.

02 / GOVERN

Approve with clarity

Review the exact action, destination, arguments, risk, expiry, and evidence before anything consequential runs.

03 / ORGANISE

Run the work hub

Calendar, inbox, tasks, projects, contacts, meetings, documents, notes, routines, and reminders in one place.

04 / REMEMBER

Keep knowledge private

Local memory, documents, retrieval, research, and source-linked answers without surrendering the personal corpus.

05 / MODEL

Bring your runtime

Use local or API models, manage compatible serving engines, and keep raw model ports behind the application boundary.

06 / VERIFY

Know what happened

Actions move through proposed, approved, running, completed, verified, failed, cancelled, or reversed states.
